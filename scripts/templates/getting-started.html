COMMON QUESTIONS

A few things worth knowing.

Can I work without internet?

Standalone desktop presentation content is designed for local use. Connected workspace tools need an internet connection.

Will my PowerPoint animations import?

No. Supported PDF and PPTX pages import as still image slides. Test important files before an event.

What if the projector is showing the wrong screen?

Check your operating system's display arrangement and Axiom audience output window. Rehearse the display setup before the event.

Where can I get help?

Use the Ask Axiom button on this page or email support with your computer type and the issue.
