Axiom Pro 0.4.8 connects reusable library content, meeting folders, presentation decks and service conversations.

- Compact presentation controls keep slide browsing usable at small desktop window sizes.
- Quiet update notices include feature highlights and a Later option. Updates remain explicit.
- Full page library view uses a responsive three- or four-column grid; List uses the full workspace width.
- Create named presentation decks inside each meeting and choose the destination when adding content from the library. Library imports can stay in the library until needed.
- Keep each service agenda, Lead notes, Tech preparation notes, shared files and messages in its own service hub.
- Archive and restore local meetings without losing presentation content. New local meetings never show another church service's conversation.
- Existing services and slides migrate into Main presentation without changing their identities. Live navigation stays within the deck sent live.

Axiom Pro 0.4.5 unifies the church workspaces and includes the scrolling, sharing and Windows update improvements.

- Presentation and Content Library each have a bounded scroll area with visible scrollbars.
- Full page previews retain their size; selecting a slide keeps your scroll position.
- Private preview and Live output stay fixed while browsing long presentations.
- Windows: Update and restart downloads and verifies the installer in Axiom, saves the current workspace, installs and restarts the app.
- Updates never install automatically on app exit. An open live output requires confirmation before updating.
- Releases include updater metadata and blockmaps for future in-app Windows updates.

Install 0.4.5 once using the installer if you are on 0.4.1 or earlier. Those older versions only open a download link. Subsequent Windows updates can use Update and restart inside Axiom. Mac updates continue to use the DMG download.

Includes 0.4.1 import, native persistence, backup and recovery fixes. Packages remain unsigned; macOS packages are not notarized. Saved data keeps the same app identity and location.

Church teams can now connect the Mac or Windows app optionally, exchange service messages, and share files in both directions. Standalone presentation still needs no account. The day’s scripture references appear in the AxiomLead agenda and Pro’s shared plan, messages and downloaded presentation. Shared files refresh automatically.

All three workspaces share the same typography, header, sidebar, controls and card styling. AxiomU has direct navigation to services, scripture and private notes. Lead handoff actions wait for a save to complete.

AxiomLead and AxiomU now have mobile navigation, larger touch controls, phone-friendly forms and dialogs, with the same design on desktop.
